# Movimentos de Amor — Políticas legais

Site estático (HTML + CSS, sem JavaScript) com a política de privacidade do app Android
**Movimentos de Amor** (`com.movimentosdeamor.app`).

- `index.html` — política em português (URL para a Google Play Console)
- `exclusao-de-dados.html` — exclusão de dados
- `en/index.html`, `es/index.html` — política em inglês e espanhol

## Publicar no GitHub Pages

1. Envie os arquivos para a branch `main`.
2. No GitHub: **Settings > Pages > Build and deployment**.
3. Em **Source**, escolha **Deploy from a branch**; em **Branch**, `main` e pasta `/ (root)`; clique em **Save**.
4. A URL será `https://<usuario>.github.io/<nome-do-repo>/`.

## Atualizar a data

Ao mudar qualquer texto, altere a data "Última atualização" (cabeçalho e rodapé) em todas as páginas:
`index.html`, `exclusao-de-dados.html`, `en/index.html` e `es/index.html`.

Antes de publicar, substitua `[NOME DO RESPONSÁVEL]` e confirme o e-mail de contato.
Se o app passar a usar um novo serviço, atualize a política antes.
